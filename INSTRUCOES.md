# Atualização para o banner animado

1. No repositório `DavidBudeli/DavidBudeli`, abra a pasta `assets`.
2. Envie:
   - `banner-dark.svg`
   - `banner-light.svg`
3. Substitua o conteúdo atual do `README.md` pelo arquivo `README.md` deste pacote.
4. Faça o commit.
5. Abra o perfil e use `Ctrl + Shift + R`.

O banner usa animações SVG/SMIL sem JavaScript:
- entrada progressiva das informações;
- movimento sutil da foto;
- linha de scanner;
- borda em movimento;
- indicador LIVE pulsando;
- tecnologias alternando;
- barra de status em movimento;
- partículas e iluminação ambiente.
