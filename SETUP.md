# Instalação

1. Crie ou abra o repositório público `DavidBudeli/DavidBudeli`.
2. Envie todo o conteúdo desta pasta para a raiz do repositório, preservando:
   - `README.md`
   - `assets/banner-dark.png`
   - `assets/banner-light.png`
   - `assets/profile.png`
   - `.github/workflows/snake.yml`
3. No repositório, abra:
   `Settings → Actions → General → Workflow permissions`.
4. Marque `Read and write permissions` e salve.
5. Abra `Actions → Generate Snake Animation → Run workflow`.
6. Aguarde a execução ficar verde. A branch `output` será criada e a cobra aparecerá no README.

Observação: os cards de estatísticas usam a instância pública por enquanto. Para evitar limite de API,
você poderá substituir depois por sua instância própria do github-readme-stats na Vercel.
